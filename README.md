# Projeto Spring Boot: Exemplo de Uso Básico

Este projeto em Spring Boot foi criado utilizando o Spring Initializr, com o objetivo de demonstrar uma configuração básica e um exemplo simples de uso de uma aplicação Spring Boot.

## Tecnologias Utilizadas

- **Spring Boot**: Framework para criação de aplicações Java baseadas em Spring de forma rápida e simples.
- **Maven**: Gerenciador de dependências utilizado para configurar e construir o projeto.
- **Java**: Linguagem de programação principal utilizada no desenvolvimento da aplicação.

## Funcionalidades Demonstradas

- Configuração básica de uma aplicação Spring Boot.
- Exemplo de criação de um endpoint REST simples.
- Uso de anotações e configurações padrão do Spring Boot.

## Exemplo de Uso

Para rodar o projeto localmente:

1. Clone o repositório:  https://github.com/seu-usuario/seu-repositorio.git

3. Acesse o endpoint `http://localhost:8080/hello` para ver a mensagem de saudação.
